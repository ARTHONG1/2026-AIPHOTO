# **App Name**: Simple Timer

## Core Features:

- Set Time: Allow users to input desired time in minutes and seconds.
- Start/Stop Timer: Control the timer with start, pause, and reset buttons.
- Countdown Display: Display the remaining time in a clear and readable format (MM:SS).
- Alarm Notification: Trigger a visual or audio notification when the timer reaches zero.
- Timer tool for contextual setting changes: Use an LLM to offer smart features. If a url to a video with cooking instructions is in the browser, use a tool to check the url for relevant cooking times, then prompt user with a shortcut to adjust timer to duration from recipe step.

## Style Guidelines:

- Primary color: Soft sky blue (#87CEEB) for a calming and focused feel.
- Background color: Light gray (#F0F0F0), creating a clean and neutral backdrop.
- Accent color: Muted green (#98FF98) for the start/stop button to represent action.
- Font: 'Inter', a sans-serif font known for its modern and clean appearance, will be used for all text elements.
- Use simple, minimalist icons for start, pause, and reset buttons.
- Center the timer display and controls for a focused user experience.
- Subtle animation for the countdown, such as a progress bar.
